# University-Events-Pin-Board
A HTML, CSS and JavaScript website where all the university's events are in one place! Add events as a host or view events as a student.

The pin board at my university is ALWAYS so cluttered and posters constantly get lost under each other. I've had this idea for a while but hesitated to execute it until I saw this challenge!

#A UNIVERSITY EVENT PIN BOARD

A place where students can find all the events going on at their campus, and event hosts can add their event posters, description and when & where to attend!

The university I attend is known as "the purple university" which is what inspired the theme for this website💜

The event categories are divided into faculty, club and open-to-all events!

It also displays whether the event is free or paid, with how much the fee is if paid.

things I would like to implement in future:

a log in system for students and hosts
an rsvp system so hosts can get a head count for the event (if they want one)
events get automatically removed after the date has passed
